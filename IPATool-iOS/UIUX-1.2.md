# 1.2 UI / UX

- 统一卡片、空状态、错误提示、搜索框、状态标签和大按钮。
- 发现：常驻输入、收藏、最近搜索、可展开统计，加载骨架与就地重试。
- 详情：固定下载操作、返回原页面的登录导航、收藏及分享、介绍折叠、历史版本筛选和手动版本入口。
- 下载：状态准确分类、文件内搜索、可见的暂停/继续/重试/导出，完整错误详情、批量选择删除。
- 已购：账号摘要、搜索和筛选、区分未登录/未同步/筛选无结果/同步失败。
- 非阻断成功提示，VoiceOver 宣读，选择触感；不添加持续闪动或依赖动画的操作。
- iPad 常规宽度采用侧栏，内容限制合理阅读宽度；窄窗口自动回到标签导航。
- 字体遵循动态字号，浅深色使用系统语义颜色。

验证：云编译、现有协议/文件测试、下载筛选边界、原生视图渲染截图。截图使用虚构应用数据，不登录账号，不启动下载。实际触控、键盘和真实账号链路仍需真机验收。
