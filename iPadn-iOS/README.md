# 使用 iPadn

从搜索一个应用，到保存需要的版本，iPadn 把整个过程放在四个页面里。

## 搜索

输入应用名称、App ID 或 App Store 链接开始搜索。可以切换商店地区和 iOS / tvOS 平台，也可以将常用应用加入收藏。

打开应用详情后，查看介绍和历史版本。输入版本号可快速筛选；已经知道版本 ID 时，展开手动版本入口即可下载。

## 下载

所有任务集中展示，支持按状态筛选和搜索。下载时显示已传输容量、百分比、速率及预计剩余时间；暂停后保留进度，继续时重新测速。网络没有返回总大小时，会显示实际已下载容量。

点按应用名称查看任务详情。暂停、继续、重试和导出按钮直接可见；长按可使用更多操作，编辑模式支持批量管理。右上角「＋」打开添加面板，可通过系统「文件」选择器导入 IPA，或添加直链下载。五个状态筛选项直接显示，大字号时自动换行。

下载完成后，任务图标从该版本 IPA 的主应用资源提取；同一应用的不同版本分别缓存。下载中或资源无法读取时显示占位图，不使用最新商店图标代替。

## 已购

连接账号后，同步你的购买记录。按名称、App ID 和购买时间查找应用，打开详情后选择版本。

图标由 Apple 商店数据自动补全；下架、区域不匹配或暂时无法联网时，应用仍会保留在列表中。

## 账号

可以保存多个 Apple 账号并切换当前下载身份。首次输入账号和密码，需要双重认证时再输入验证码。

当前接口不提供 Apple 原生头像；账号页直接显示账号名称和邮箱，不设置自定义头像。

请求验证在本机后台完成，不额外显示验证组件或内部阶段。需要双重认证时，登录页会提示输入验证码。

## 设置与扩展

在账号页进入设置，调整并发下载数、队列上限、通知、商店、版本来源和外观。iPad 大窗口使用侧栏，小窗口自动适配标签导航；文字大小跟随系统。

支持从「文件」打开 IPA，也可使用快捷指令或 `ipadn://` 链接。需要代理安装时，可配置自己的 HTTPS 清单服务及 Surge/Loon 规则；通常直接导出 IPA 到签名工具即可。

## 查找已下架应用

搜索页会同时匹配当前账号的已购记录、收藏、下载、本机查询记录，以及 iPadn 自己维护的名称目录。登录后首次进入搜索或已购页会同步尚未缓存的购买记录；之后可下拉手动刷新。

名称目录目前收录 Forward，支持 `Forward`、`Forward - AI Media Hub`、`Forward - 新视界` 和 `新视界`，无需先输入 App ID，也不要求以前下载过。目录随应用内置，并尝试从本仓库更新；不能联网时仍可使用内置和缓存内容。

目录不是完整的下架应用数据库。尚未收录且没有任何本机或已购记录的应用仍需 App ID。搜索结果只表示存在资料，实际下载取决于 Apple 的授权与文件可用性。

## TestFlight 测试版

当前版本不提供 TestFlight 账号接入或直接下载测试版 IPA。已有 IPA 文件仍可导入和管理。

仍有测试资格且构建有效时，可通过 TestFlight 的「以前的构建版本」选择开发者仍提供的版本。每个构建最多测试 90 天，也可能被开发者提前停止；曾参加过测试不代表过期或已移除版本仍可重新下载。

[TestFlight 使用说明](https://testflight.apple.com/)

## 常见问题

**下载后可以直接安装吗？**

应用提供未签名安装包，需要自行签名。下载的其他应用是否能运行，取决于其授权和签名条件。

**为什么某个版本无法下载？**

版本可能已下架、不在当前地区提供，或账号没有对应许可。可检查地区、切换拥有许可的账号，或尝试其他版本。

**移除账号会删除安装包吗？**

不会。移除账号会清除该账号的登录信息和已购缓存，已下载文件仍保留在下载页。

**下载卡住了怎么办？**

检查网络后暂停再继续。失败的 Apple 下载任务可以在原任务上重试刷新授权链接，不重复加入队列；点按任务名称可查看完整错误信息。

**本地文件无法读取时怎么办？**

应用保留原文件并显示提示，其他任务可继续使用。请先导出或备份文件再检查；不要通过清空账号或删除整个数据目录来解决。清除版本查询缓存和恢复默认设置会保留账号与下载包。
