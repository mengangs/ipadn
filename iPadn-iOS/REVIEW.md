# 全项目检查与修复

检查基线：`fa7f76b50db8a5e2acf580849e542ea37c4de0f6`（main）。变更见 [PR #1](https://github.com/mengangs/ipadn/pull/1)。保留 iPadn 名称、图标、黑白主题、SwiftUI 原生架构和现有功能；未增加旧项目运行依赖。

## 修复与优化

| 范围 | 确认的问题与处理 |
| --- | --- |
| 下载和重试 | 失败 Apple 任务刷新后曾新建任务再删除旧任务，可能受队列上限影响且丢失原任务上下文。现原位更新，保存失败保留原任务；已有待处理文件继续使用。 |
| 回调与恢复 | 暂停回调及旧下载完成回调可能晚于状态变化到达。现校验任务身份，使用独立接收文件，防止旧回调覆盖新任务；恢复暂停任务等待断点数据完成。 |
| 存储 | 入队/导入先保存再发布，避免界面报告成功但重启后任务丢失；删除安装包先移到暂存位置，任务保存失败恢复原文件。 |
| 文件保护 | IPA 元数据/图标增加 CRC 对照，拒绝校验失败的资源；损坏的本地 IPA 曾设置全局存储错误，阻断所有下载。现仅提示并保留原件；拒绝越界路径、目录和指向 Packages 外的符号链接。 |
| 账号与已购 | 登录完成前确认账号未被切换；最低系统版本不再误用年龄分级；空或缺少状态码的购买记录响应不覆盖缓存；损坏收藏/已购文件不写入空记录。 |
| 设置兼容 | 较旧设置缺少字段时保留已有选择，为缺少字段补默认值，限制并发和队列范围。 |
| 服务与缓存 | HTTP 会话一次初始化，下载重定向禁止 HTTPS 降级；并发启动本机服务共享同一个监听器；缓存清理后正在执行的查询不能重新写回；版本缓存限制期限和条目数，缓存写入失败不隐藏有效查询结果。 |
| 搜索和详情 | 增加可点按的搜索提交入口；收藏变化即时更新本地搜索记录；切换商店时清空旧结果；登录/换账号后重新查询历史版本，清除过期版本列表。 |
| 可访问布局 | 任务状态与操作在横向空间不足时纵向排列；安装确认使用非破坏性操作角色；详情中的平台名称随当前平台显示。 |
| 测试隔离 | Debug 演示模式曾写入正式设置和任务文件。现使用独立的设置域、钥匙串服务、临时文件目录；预览下载管理器默认不落盘。 |
| 构建与截图 | 主分支最近一次截图失败为 `No devices are booted`。现明确选择、启动模拟器并等待就绪；PR 自动运行构建，测试结果检查实际执行数量。 |

## 清理边界

删除未引用的 `StatCell`、`StatusBanner` 组件及过时的受跟踪 `verification.json`；新校验报告放入已忽略的 `build/`。版本缓存按 24 小时期限和最多 200 项维护。

保留 ZIPFoundation 0.9.19、全部 SAP/WASM 文件、组件来源和许可证声明：它们仍被功能或构建依赖。保留账号、收藏、已购记录、断点数据、下载包和必要资源；没有执行清空用户数据、全目录删除或删除不明文件的操作。原有 UI/UX 历史文档保留为设计记录。

## 验证边界

新增回归覆盖旧设置解码、路径/符号链接、归档授权路径、空购买响应、原位任务重试、保存失败、意外取消、HTTPS 重定向与并发本机服务启动。项目结构和离线 WASM 检查可在 Linux 执行；Xcode 编译、XCTest 和界面截图以对应提交的 macOS Actions 结果为准，见 [VERIFICATION.md](VERIFICATION.md)。

无需 Apple 凭据的测试无法证明真实登录、免费许可获取、下载授权、tvOS 接口、后台恢复或签名后安装可用。这些保持为真机验收项，不以界面示例数据代替。
